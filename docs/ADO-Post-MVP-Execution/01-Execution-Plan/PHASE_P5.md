# P5 — 受控主动研发

状态：PLANNED；实际状态 OPEN。入口：P4 阶段门已验收，仓库与批准文件核查有效，任务依赖及权限已核实。准备工作可先行，但不可提前视为阶段通过。

## 工作步骤
1. Project Director 检查现状、批准范围、风险和依赖；Product Manager 定义可验收成果。
2. Architect 和适用的 UI/UX 制定方案与项目隔离、权限、回滚和测试设计；需要变更基线时提出审批。
3. 先建立只读监测和证据化建议，再在人工预授权的低风险范围试行隔离执行；生产自主操作关闭。
4. 开发在授权的隔离工作区实施；QA 独立执行适用的正向、负向及回归测试；Release 准备交付证据并按策略申请批准。
5. 汇总 风险分类、授权边界、审计、暂停撤销、隔离执行测试及人工验收。 依 `05-Acceptance/PHASE_GATES.md` 提交人工验收；不满足则保持 BLOCKED/未通过并追踪整改。

输入：前置阶段证据、批准的需求/架构/设计、仓库提交、对应 Issue 和授权。输出：可追溯的任务记录、设计/代码/测试/审批/回滚证据及阶段报告。详细任务与依赖见 `03-Backlog`；实施前按现状细化，不扩大冻结范围。
