# Quality Checklist

- [ ] 任务、项目、实际基线提交及文档版本已核实；范围及每条需求映射至验收和测试。
- [ ] 项目权限、工作区、知识、数据和凭证隔离；负向测试覆盖相关边界。
- [ ] 架构、接口、数据、错误处理、可访问性和设计适用性已审查；任何例外及决策可追溯。
- [ ] 按风险运行必要静态、单元、集成、UI、回归、安全及依赖检查；列出环境、命令、结果、失败和未运行原因。
- [ ] 独立 QA 验证真实业务行为，不依赖开发者的口头结论；失败项记录严重度与处理。
- [ ] 任务、提交、PR、测试报告、审批及产物关联；日志无秘密；审计和审批持久化。
- [ ] 知识与技能有来源、版本、适用范围、审核状态和回滚；指标分母、样本及预算清楚。
